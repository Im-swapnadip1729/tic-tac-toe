# Tic Tac Toe
This is a simple Tic Tac Toe game built with React and Vite. It features a clean and responsive design, allowing players to enjoy the game on various devices. The game includes basic functionality such as player turns, win detection, and a reset option.
you can enter player names and choose to play against another player or the computer. The game also keeps track of the score and provides a fun and interactive experience for users.

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## Run on local
1. Clone the repository:
   ```bash
   git clone https://github.com/Im-swapnadip1729/tic-tac-toe.git
    ```     
2. Navigate to the project directory:
    ```bash 
    cd tic-tac-toe
    ```
3. Install dependencies:
    ```bash 
    npm install
    ```
4. Start the development server:
    ``` bash 
    npm run dev
    ```
5. Open your browser and go to `http://localhost:5173` to see the game.



## React Compiler
